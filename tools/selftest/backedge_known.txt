# 已知的【所需回边缺失】文件（缺陷清单，不是放行证明）
#
# ★ 判据：只有**存在可达的正常继续路径或 `continue` 路径**的循环才需要回边。
#   若循环体的所有可达路径都以 `break`/`return` 结束，那么它本来就不需要回边，
#   **没有回边不是缺陷**。
#
# ⚠️ 本文件曾被写错并因此产生一批假红（已撤回）：
#   早期判据是"结构化循环数 > 平面回边数"与"循环头的前驱数 < 2"，
#   于是把 `while(1){ …; break; }` 这种**必然一次就跳出**的循环判成了"丢回边"。
#   实测 `26_scope4.sy` 第 81 行的外层 `while(1)`：体内最后一条语句是第 109 行的
#   **无条件 `break;`**，入口边正常（`L0 → L1`），**本来就不需要回边**；
#   当时"把它当缺陷并要求插桥块补边"的结论**已撤回**——那样改会把 `break` 变成再循环。
#
# 用法：新增一个就红；确认不再缺失就删一行。
# 允许为空——为空表示当前没有已知的所需回边缺失。
