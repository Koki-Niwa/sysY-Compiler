# `--emit=initplan` 的样例对（S04 起）

`example.sy` 与它的真实输出 `example.emit-initplan.txt`，由**关卡**在 C5 组里
用 `cmp -s` 逐字节比对。

## 为什么必须有它

`--emit=initplan` 是**冻结的对外契约**（S05 的 IRGen 要消费它），而
提示词 §4.3 里的示例是**手写**的，与实际输出有三处排版差异：

1. `:data` 的 `(偏移 值)` 实际是**一行一对**，示例写成了全挤一行；
2. `StoreExpr` 的子树折叠成一行（不折叠的话 `86_long_code2.sy` 单个文件就超 2 MB 预算）；
3. `MemcpyConst` 的值一行一个、收尾括号位置不同。

S03 的 `--emit=sema` 就是靠一份样例对 + 关卡里一条 `cmp -s` 把格式钉死的
（那一关的例子**确实**与规则自相矛盾过，是关卡抓出来的）。这里照搬同一做法：
**文字描述会漂，样例对不会。**

## 这份样例覆盖的形态

| 形态 | 出现在 |
|---|---|
| `:zero`（零初始化不产生数据） | `zg` |
| `:data` 稀疏、只列非零、偏移升序 | `g`（注意偏移 12 **缺席** ⇒ `g[1][1] = 0`） |
| 浮点常量用精确的十六进制浮点 | `h` → `0x1p+0` / `0x1p-1` |
| `Zero` + `StoreConst` 的"全零 + 首元素"策略 | `main/a`（4096 个元素只有 **2 条动作**） |
| **零动作**（未初始化的局部变量不插零填充） | `main/b` |
| 标量加花括号（`{5}`）合法 | `main/c` |
| 局部初始化器里的运行期表达式 | `main/d` → `StoreExpr` |
| 标量对象的动作 | `main/k` |

⚠️ `g` 那一项是 §3.1 里那条**规范与 C 冲突**的裁决的落地证据：
`{1,2,{3},5,6}` 必须得到 `{{1,2},{3,0},{5,6}}`，所以偏移 12 处是 0、不出现。
